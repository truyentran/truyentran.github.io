AI for Science

AI co-scientist.

An AI colleague for research that proposes ideas, checks them against the literature, runs the experiments, and tells you honestly when the answer is no. We build the co-scientist and the tests that show whether it beats a strong non-AI method on problems it has never seen.

View systems Study with us
The aim

Systems that ground themselves in literature and data, generate hypotheses, write analysis code, plan experiments, and communicate findings, with experts in the loop.

The standard

On each task, at a stated budget: did agent-driven research beat the strongest non-AI alternative at matched compute, on data it never saw? A null or negative answer is a valid result, and we report it.

Status

Research prototypes and pre-registered tests. Results below are from internal technical work, not yet peer reviewed.

Three strands

Ideas, tests, and a domain to prove it on.

IGNITE

Generating and filtering ideas

A platform that produces original, falsifiable, small-lab-feasible research directions, then attacks them. Each idea must resolve against real prior art before it counts as novel. An outage in the search is never read as “nothing found”.

Result so far: in an adversarial audit of 26 ideas, none was cleared as novel, and the four that survived were weakened by kill-tests into narrower claims that still need checking.

co-scientist harness

Do agents beat search?

Runs coding agents on a contracted computational task under evaluation the agent cannot touch, against non-LLM search at matched compute, on sealed data scored once. Every number in a report can be re-derived from stored artefacts.

Inverse design

Materials, with the claims audited

Generative models for crystal structures and magnetic materials, built on published methods and then checked against pre-registered bars, with the audits kept as results.

What the tests said

Mostly honest nulls, and a few real signals.

Cancer dependency prediction

A coding agent beat the best non-LLM method by +0.025 recall@100 (95% interval +0.012 to +0.039), winning on 16 of 24 held-out tumour types. The pre-set bar was +0.03, so the registered verdict is a null.

Combinatorial geometry (Heilbronn)

An early run found many new records, but a plain script reproduced about half of them, and a later three-arm run did not support the claim that the co-scientist procedure reliably finds new kinds of move. The early signal did not replicate.

Reaction yield task

Retired as a discovery testbed: a non-LLM method already solved 97.4%, leaving too little headroom for any agent to show a win. We kept the sandboxed evaluator and sealing method for the next task.

Generative crystal design

A conditional flat GFlowNet did not beat tuned Bayesian optimisation, and a multi-potential committee reward saved only 3.6% against a pre-registered bar of 10%. Part of the hierarchical model’s apparent advantage came from an ordering bias we found and corrected. No generated candidate has been validated as stable.

Where this goes

The next step is a task with real headroom, onboarded from a contract file alone, and a verdict on sealed data. The aim is not a claim that AI can do science; it is a standard of evidence for when it can.
